# Patrick Yao — Personal website

Personal website: [yaopingan.com](https://yaopingan.com).

## Research paper

Edit `data/minotaurs-lament.html` for the full paper (inline LaTeX uses `\(...\)`, display math uses `\[...\]`). Run `npm run render:paper` to regenerate `writings/minotaurs-lament.html` and its locally hosted KaTeX assets. The Vercel build also runs this step. Figures are in `assets/minotaurs-lament/`; WebP copies are used for reading, with links to the original images.
